Kalau gagal tersambung.

"PC tujuan tidak menerima koneksi LAN"

Sakelar Sambung lewat IP di PC tujuan belum menyala, atau firewall memblokir. Di PC tujuan buka Keamanan Windows›Firewall›Izinkan aplikasi, centang TryDesk untuk Private, dan pastikan Wi-Fi atau kabelnya diset sebagai jaringan pribadi.

"Tidak ada TryDesk yang menjawab"

Kedua perangkat tidak di jaringan yang sama, atau Wi-Fi tamu dan hotspot memisahkan perangkat. Pakai Wi-Fi yang sama atau kabel LAN.

Kemarin bisa, sekarang tidak

Alamat IP bisa berubah setelah router dinyalakan ulang. Lihat lagi alamatnya di Beranda PC tujuan.

Ada antivirus dengan firewall sendiri

Sambungan ini memakai port TCP 7171. Izinkan TryDesk juga di antivirus itu.

Step 1 of 4

In Settings›Network. When Windows asks about the firewall, choose Private networks, then Allow access.

If it doesn't connect.

"The other PC doesn't accept LAN connections"

Connect by IP is off on that PC, or a firewall blocks it. On that PC open Windows Security›Firewall›Allow an app, tick TryDesk for Private, and make sure its Wi-Fi or cable network is set to Private.

"No TryDesk answered at this address"

The devices are not on the same network, or a guest Wi-Fi or hotspot keeps devices apart. Use the same Wi-Fi or a LAN cable.

It worked before, not now

The IP address can change after the router restarts. Check the address again on that PC's Home.

An antivirus with its own firewall

This connection uses TCP port 7171. Allow TryDesk in that antivirus too.
